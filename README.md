# Capital AI

A free, mobile-first Hebrew portfolio tracker and PWA prototype.

## Features
- Portfolio holdings and manually entered USD prices
- Profit/loss calculations
- Watchlist
- Local browser storage and JSON export/import

## Important
This is a prototype. It does not provide live stock prices, broker integration, or investment advice. Data is stored on the user's device. Publish through GitHub Pages to make the app accessible as a website.
